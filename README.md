# Moodrot Chaos Legend 💙

A hidden reaction ecosystem for Facebook comments.

Features:

* Shared reactions via Firebase
* Chaos reactions
* Animated effects
* Community-only overlays
* Secret vibe system 😈

Supported:

* Chrome (PC)
* Edge (PC)
* Kiwi Browser (Android)

PC Installation

1. Download ZIP from Releases
2. Extract ZIP
3. Open:
   chrome://extensions
4. Enable Developer Mode
5. Click:
   Load unpacked
6. Select the EXTRACTED Moodrot folder

Example:

Downloads/
└── moodrot-chaos-legend/
├── manifest.json
├── content.js
└── style.css

Select:
moodrot-chaos-legend

Do NOT select the ZIP file directly.

Android Installation

Google Chrome mobile does NOT support extensions.

Use:

* Kiwi Browser
* Yandex Browser

Steps:

1. Install Kiwi Browser
2. Download the ZIP
3. Extract the ZIP
4. Open:
   chrome://extensions
   inside Kiwi Browser
5. Enable Developer Mode
6. Click:
   Load unpacked
7. Select the extracted Moodrot folder

Firebase powers the shared reaction system 💙
